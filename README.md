---

O **LexaByte** é uma plataforma web para acesso e organização de conteúdo digital em português.
O sistema centraliza materiais de mídia brasileira em um ambiente moderno e acessível, desenvolvido
em equipe como projeto institucional do curso de **Análise e Desenvolvimento de Sistemas**
no **SENAI Mariano Ferraz — São Paulo, SP**.

## `>_ arquitetura`

Arquitetura **three-tier** com separação clara entre apresentação, lógica de negócios e persistência.

```
  ╔═══════════════════════════════════════╗
  ║  [ PRESENTATION ]                     ║
  ║  React  ·  Interface Web              ║
  ╚══════════════════╤════════════════════╝
                     │  HTTP / REST
  ╔══════════════════▼════════════════════╗
  ║  [ BUSINESS LOGIC ]                   ║
  ║  Node.js  ·  API REST                 ║
  ╚══════════════════╤════════════════════╝
                     │  Query / ORM
  ╔══════════════════▼════════════════════╗
  ║  [ PERSISTENCE ]                      ║
  ║  MySQL  ·  Dados Relacionais           ║
  ╚═══════════════════════════════════════╝
```
